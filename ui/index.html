      Cookies and site data together: signs you out of every site. Saved passwords are kept by the iOS Passwords app, not Snorkle, and are not affected.

      CSS and JavaScript added here run on pages of that domain and its subdomains, isolated from the page's own scripts. Changes apply when matching pages load. Only add code you wrote or trust.
